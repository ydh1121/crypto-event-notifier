# Viewer Build 46 usability correction

Primary-content ordering is now a hard Viewer rule.

- Research: coin list + selected decision workspace first; listing-history research below.
- Assets: holdings + selected holding + averaging/take-profit tools first; portfolio history below.
- Sector: sector ranking + selected sector + constituent coins first; market lifecycle and secondary summary below.
- Sector is a top-level navigation item again because it is a primary discovery task for ordinary users.
- Research/Sector no longer use a duplicated secondary journey tab.

Supporting research or operational context must not occupy the first viewport unless it directly changes the user's immediate decision.
